### 🚨 AusAware

A free, ad-free live view of what Australian emergency services are dealing with right now, deepest in NSW.

It merges public data feeds (fire, traffic, power, weather, beaches, aircraft, public transport) with unencrypted radio and pager traffic picked up off-air by volunteer-run receiver nodes. The result is a live map, a feed, a searchable log and a Discord bot.
